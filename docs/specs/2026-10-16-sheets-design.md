## Apps Script (`apps-script/Code.js` → 선생님이 Code.gs에 붙여 넣기)

- GET `?action=bootstrap` → `{ ok, questions:[{id,q,choices,answer,explain}], lines:{start:[..],…} }`
- GET `?action=board` → `{ ok, ranking:[…정렬], messages:[…숨김 아님, 최근 100] }`
- POST(본문 JSON, Content-Type text/plain → CORS 사전 요청 없음) `record` / `message` / `finishers`(비밀번호) / `hide`(비밀번호)
- 기록 검사: 서버가 점수를 다시 계산, 최고층 1~600, 정답+오답 ≤ 그 층까지의 퀴즈 수, 완주면 600층·등반 60초 이상, 등반 시간 ≤ 제한+5초, 이름 1~10자, 반 1~30. 같은 판번호는 한 번만(CacheService). 쓰기는 LockService.
- 한마디: 그 학생이 랭킹에서 완주로 되어 있어야, 30자, 금지어(공백·기호 무시) 차단.
- 비밀번호가 필요한 일은 POST 본문으로 (주소에 넣지 않음).

## 게임 쪽 (`js/sheet.js` + 기존 파일)

- `config.js` `sheet: { url: '' }` (빈칸이면 시트 없이 내장 문제·문구로)
- 시작할 때 bootstrap (5초) → 문제은행·말풍선 교체, 실패하면 내장
- 판이 끝나면(테스트·연습 제외) 기록 전송. 실패하면 기기에 모아 두었다가 다음에 다시 보냄. 결과 화면에 저장 상태
- 완주 + 저장 성공 → 결과 화면에 한마디 칸(30자)
- 보드 상자, 선생님 상자(연결 상태·완주자 목록·한마디 숨기기)
- 기록에 `maxCombo`, `runId` 추가

## 테스트

Apps Script 순수 함수(점수·검사·순위 비교·한마디 정리·문제/문구 읽기) + 가짜 스프레드시트로 doGet/doPost 전체 흐름(설치, 기록·최고 기록 갱신, 중복 무시, 한마디 권한·금지어, 숨기기 비밀번호, 완주자 목록) + 내장 문제와 시트 씨앗이 같은지. 게임 쪽 클라이언트는 가짜 fetch로(시간 초과, 실패 시 모아 두기, 테스트 기록 안 보냄). 브라우저: 가짜 서버로 결과 화면 저장 상태·한마디·보드·선생님 상자.
실제 구글 연결은 선생님 계정이 필요 → 설치 안내서 후 함께 확인.
