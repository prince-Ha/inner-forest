## 결정 (사용자 답)

| 항목 | 결정 |
|---|---|
| 진입 | 600층 완주 증명서 뒤 "1000층까지 도전?" 버튼. 안 누르면 지금처럼 끝 |
| 조작 | ◀▶는 그대로(누르고 있으면 걷기). 게임 화면 아무 데나 누르면 점프. 밧줄 앞에서 점프 → 잡기, 잡은 채 ◀▶로 오르내림 |
| 추락 | 떨어진 만큼만 (아래 발판에 착지). 맵 바닥으로 보내지 않음 |
| 시간 | 601층부터 제한 없음 (600층 증명서 뒤 타이머 멈춤) |
| 기록 | 랭킹 최고층이 1000까지 올라가고 층당 점수 그대로. 1000층 도달 = '정복' 표시 + 별도 정복 증명서 |
| 문제 | 800층·1000층 두 문제만. 코드에 고정 (시트에서 안 읽음). 내용은 선생님이 줌 |
| 맵 | 손으로 짠 맵 4장(601~700, 701~800, 801~900, 901~1000). 떠 있는 좁은 발판·밧줄/사다리·포탈. 발판은 2칸 이상(휴대폰 조작 고려) |
| 장애물 | 밀어내는 솜뭉치(새로) + 가시공·바나나·도토리·돌풍 재활용 |
