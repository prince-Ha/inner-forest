## 1. 이번 단계 목표

사용자: "600층 한 번에 갈 수 있는 걸로". 처음 프롬프트의 퀴즈(약 20층마다 30문제, 4지선다, 일시정지, 해설, 중복 없음), 15분 제한, 점수(빨리 도착 + 콤보 + 정답)를 넣는다.

**성공 기준**
1. 1층에서 600층까지 한 맵으로 이어지고, 검증 봇·공정성 봇이 통과한다.
2. 퀴즈 30개가 10·30·…·590층에서 한 번씩만 나오고, 그동안 게임 세계가 멈춘다.
3. 남은 등반 시간이 15:00에서 줄고 0이 되면 시간 종료 화면.
4. 완주/시간 종료 화면에 점수 내역이 맞게 나온다(아래 공식).
5. 폰에서 맵 만들기가 너무 오래 걸리지 않는다(목표: 학생 화면 3초 이내).

## 2. 확정된 결정

| 항목 | 결정 |
|---|---|
| 15분 제한 | **등반 시간만** 15분 (퀴즈 시간 제외). 총 플레이 시간(퀴즈 포함)은 따로 기록. `config.js`의 `timeLimitSec: 900` (0 = 제한 없음) |
| 시간 종료 | "시간 종료!" 화면, 그때까지 최고 층으로 점수, 완주 아님 |
| 퀴즈 위치 | 10·30·50·…·590층 (20층마다 30개). 그 층에 처음 서면 출제 |
| 오답 | **벌칙 없음**, 그 문제 점수만 못 받음. 정답·해설은 보여 줌 |
| 점수 | 최고 층 × 10 + 완주 3,000 + (완주 때만) 남은 등반 초 × 5 + **정답 × 200** + 최고 콤보 × 10 |
| 순위(3단계) | 완주한 학생이 항상 위 → 점수 → 등반 시간 짧은 순 |
| 문제 | 이번엔 내장 임시 문제 40개(중3 과학), 매 판 무작위 30개. 3단계에서 시트 문제로, 연결 실패 시 내장 문제 |
| 최고 난이도 시험 모드 | 501~600 구간으로 흡수 → 시작 화면 버튼·`hardTest`·모드 전환 코드 삭제 |
| 구간 연습 버튼 | 장애물 구간 첫 층마다(61·101·151·201·281·361·441·501). 2단계에서 선생님 모드로 옮김 |

예) 10분 완주, 정답 24, 최고 콤보 80 → 6,000 + 3,000 + 300×5 + 24×200 + 800 = **16,100**
예) 420층에서 시간 종료, 정답 18, 콤보 60 → 4,200 + 3,600 + 600 = **8,400**

## 4. 퀴즈

- **퀴즈 층은 쉬는 자리**: 퀴즈 층과 바로 위 층에는 장애물을 두지 않고, 퀴즈 층 발판은 금 간 발판이 되지 않는다(퀴즈 끝나자마자 맞거나 떨어지지 않게).
- **표지판**: 퀴즈 층 발판 위에 "?" 나무 표지판(오리지널 픽셀아트). 풀고 나면 "✓" 표지판.
- **출제 조건**: 진행 중(playing)이고, 발이 땅에 닿아 서 있고(idle), 퀴즈 층 발판 위이고, 그 층 퀴즈를 아직 안 풀었을 때. 이때 줄 서 있던 입력을 버린다.
- **멈춤**: 상태 `quiz` 동안 고정 간격 루프의 시계·장애물·바람·금 간 발판·콤보 시간·등반 시간이 모두 멈춘다. 총 플레이 시간만 흐른다.
- **화면**: "과학 퀴즈 n/30", 문제, 보기 버튼 4개(A~D). PC는 1~4 키도. 고르면 정답/오답 + 정답 표시 + 해설 + [계속 오르기]. ◀▶는 퀴즈 중 무시.
- **문제 고르기**: 판 시작 때 사용 가능한 문제에서 무작위 30개를 섞어 순서대로 낸다(중복 없음). 문제가 30개보다 적으면 다 쓴 뒤 다시 섞어 쓴다(선생님 모드에서 경고 — 2단계).
- **다시 오기**: 떨어졌다 다시 올라와 지나간 퀴즈 층에 서도 다시 안 나온다.
- **과학 상식 말풍선**은 퀴즈 층과 겹치지 않게 20·40·…층(최고 층 갱신 때)으로 옮긴다.
- 내장 임시 문제 40개: 중3 과학 단원(화학 반응의 규칙과 에너지 변화, 기권과 날씨, 운동과 에너지, 자극과 반응, 생식과 유전, 에너지 전환과 보존, 별과 우주)에서 고르고, 형식은 3단계 시트와 같게 `{ id, q, choices[4], answer(0~3), explain }`.

## 5. 시간·점수 화면

- 오른쪽 위 타이머: "남은 14:59"처럼 등반 시간 기준으로 줄어듦, 마지막 60초 빨간색. 그 아래 "최고 N층".
- 완주 화면과 시간 종료 화면은 같은 결과 상자: 제목(완주! / 시간 종료! / 연습 완주!), 점수 내역 표(층 점수, 완주 보너스, 빨리 도착, 퀴즈 n/30, 최고 콤보, 합계), 등반 시간, 총 플레이 시간, 추락 횟수, [다시 하기].
- 연습 판은 결과에 "기록 안 남음" 표시(3단계에서 저장 안 함).

## 7. 맵 만들기 시간

600층은 지금(140층)보다 4배 이상이라 검증(모든 계단 봇·추락 측정·공정성 봇·배치 재시도)이 폰에서 오래 걸릴 수 있다.
1. 먼저 PC에서 재고, 폰 속도는 PC의 약 3~4배로 본다.
2. 3초를 넘을 것 같으면: 검사는 테스트(tests.html)와 선생님이 시드를 바꿀 때만 하고, 학생 기기는 **검사를 통과한 시드 번호와 장애물 배치 번호**(`config.js`에 적어 둔 값)로 생성만 한다. 이 값이 지금 설정과 맞는지는 테스트가 확인한다.
3. 학생 화면에는 그동안 "숲을 만드는 중…" 표시.

## 8. 테스트

- 퀴즈 층: 10·30·…·590, 30개
- 퀴즈 판: 30개 중복 없음, 문제가 30개보다 적으면 다시 섞어 채움, 같은 층 두 번 안 나옴
- 점수: 위 두 예시가 정확히 16,100 / 8,400, 미완주는 빨리 도착 0
- 600층 기본 맵: 오류 없음, 퀴즈 층과 그 위 층에 장애물 없음, 퀴즈 층 발판은 금 간 발판 아님, 돌풍은 441~500에만, 501~600에 겹친 장애물·1.5배·깊은 추락(50층 이상)
- 공정성: 조심하는 봇이 61~600 맞음 0·밀림 0
- 설정 검사: timeLimitSec, quiz, score 잘못된 값 안내
- 브라우저 확인: 퀴즈 열림/멈춤/답/계속, 시간 종료, 결과 점수 표, 폰 크기 화면, 맵 만들기 시간 측정
