# 과학 인내의 숲

좌우 버튼만으로 거대한 나무 속 600층을 오르는 모바일 세로형 웹게임입니다.
버튼을 **누를 때마다 한 칸씩** 톡 올라가고(무한의 계단처럼), 잘못 누르면 허공으로 뛰어 실제 물리처럼 아래 발판까지 떨어집니다.
연속으로 빠르게 오르면 콤보가 쌓이고, 효과음과 말풍선(20층마다 과학 상식)이 나옵니다.

- **과학 퀴즈 30문제**: 10·30·50…590층에 처음 서면 게임이 멈추고 4지선다 퀴즈. 정답이면 200점, 틀려도 벌칙은 없고 정답·해설을 보여 줘요.
  구글 시트 **문제** 탭의 문제에서 매 판 30개를 뽑아요. 시트가 없거나 연결이 안 되면 게임 안의 기본 문제 40개(중3 과학)로 해요.
- **15분 제한**: 퀴즈 푸는 시간을 뺀 등반 시간. 오른쪽 위에 남은 시간, 마지막 1분은 빨간색. 다 되면 "시간 종료!"
- **점수** = 최고 층 × 10 + 완주 3,000 + (완주 때만) 남은 등반 초 × 5 + 퀴즈 정답 × 200 + 최고 콤보 × 10
  완주/시간 종료 화면에 점수 내역, 등반 시간, 전체 시간(퀴즈 포함), 추락 횟수가 나와요.

| 층 | 장애물 |
|---|---|
| 1~60 | 없음 (계단·낭떠러지 익히기) |
| 61~100 | 가시공: 줄을 따라 좌우로 왕복 |
| 101~150 | 원숭이: 벽 가지에서 바나나를 던짐 (팔을 들면 곧 던진다는 신호) + 가시공 |
| 151~200 | 금 간 발판: 밟으면 곧 부서지고 3초 뒤 다시 생김 + 가시공 |
| 201~280 | 도토리(그림자가 진해지면 곧 떨어짐) + 섞임 |
| 281~360 | 섞임, 1.15배 빠르기 |
| 361~440 | 섞임 + 두 개 겹침, 1.25배 |
| 441~500 | 돌풍: 4초마다 나뭇잎 예고 → 1초 바람(왼쪽·오른쪽 번갈아). 바람 속에서 0.35초 넘게 서 있으면 한 칸 밀림 |
| 501~600 | 최고 난이도: 2층마다 장애물(절반은 겹침), 1.5배, 금 간 발판 많음, 추락 한도 없음 |

퀴즈 층과 그 바로 위 층에는 장애물이 없어요. 장애물에 맞으면 튕겨나가 떨어지고 콤보가 끊깁니다. 착지 후 잠깐 깜빡이는 동안은 안 맞아요.

**처음 화면**: 이름 → 3학년 반 → 캐릭터(하치와레·오데) → 시작하기. 입력은 그 기기에 기억돼요.
게임 중 왼쪽 위 **⏸ 일시정지**(등반 시간 멈춤)와 **🏠 처음 화면**(그만두면 최고 층까지 기록돼요).
완주하면 **증명서 보기** → 이름·반·날짜·기록·캐릭터가 들어간 증명서와 [사진으로 저장].

**구글 시트** (설치: `설치안내.md`): 판이 끝나면 기록을 시트로 보내고 결과 화면에 "기록 저장! 전교 N등 · 우리 반 N등".
완주한 학생은 결과 화면에서 **한마디**(30자, 금지어 차단)를 남겨요. 처음 화면 **[랭킹 · 한마디]**와 결과 화면 **[랭킹 보기]**에서
보드(우리 반 / 전교 / 한마디 탭, 내 기록 강조)를 봐요. 말풍선 문구도 시트 **말풍선** 탭에서 바꿀 수 있어요.
와이파이가 끊기면 기록은 그 기기에 보관했다가 다음에 게임을 열 때 보내요. 시트가 없어도 게임은 그대로 돼요.

**선생님 모드**: 처음 화면 구석의 [선생님] → 비밀번호(`config.js`의 `teacher.password`, 지금 6666).
- **테스트 모드**: 화면에 "테스트" 표시, 준비 화면에 **구간 연습** 버튼(61·101·…·501층), 일시정지 상자에 층 이동·봇·1분 남기기, 퀴즈에 건너뛰기. 테스트 판은 기록이 남지 않아요.
- **설정 요약**: 반 개수·층수·퀴즈·문제은행·시간·점수·맵 상태.
- **구글 시트**: 연결 상태 한 줄, **완주자 목록**(반별, 먼저 완주한 순), **한마디 숨기기**.
- 비밀번호는 간단한 화면 잠금이에요(코드를 보면 찾을 수 있음). 완주자 목록·한마디 숨기기는 구글 쪽이 시트 **설정** 탭 비밀번호로 다시 확인해요.

캐릭터 그림은 원본을 도트로 옮긴 `js/characters-art.js`에 있고(교육용), 이름·크기는 `js/characters.js`에 있어요. 캐릭터마다 말풍선 말투가 달라요(구글 시트 **말풍선** 탭의 **캐릭터** 칸).

## 실행하기

- **가장 간단한 방법**: `index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다.
- **조작**: 화면 아래 ◀ ▶ 버튼 (휴대폰), 또는 키보드 ← → / A D (PC). 누를 때마다 그 방향으로 한 칸.
  - 다음 계단이 있는 쪽을 누르면 오르고, 바위·벽이면 부딪히고, 허공이면 떨어집니다. 누르고 있어도 반복하지 않아요.
  - 1.5초 동안 안 오르거나 실수하면 콤보가 끊깁니다. 왼쪽 위 스피커 버튼으로 소리를 끌 수 있어요.
  - 퀴즈는 보기를 누르거나 PC에서 1~4 키, [계속 오르기]는 Enter.

## 설정 바꾸기 — `config.js`

메모장 등으로 `config.js`를 열어 숫자만 바꾸고 저장한 뒤 새로고침하면 바로 반영됩니다.

| 항목 | 뜻 |
|---|---|
| `school` | 학년(3)과 반 개수(10) — 처음 화면의 반 고르기 |
| `teacher.password` | 선생님 모드 비밀번호 (따옴표 안에). 시트 **설정** 탭 비밀번호와 같게 |
| `sheet.url` | 구글 시트 Apps Script 웹 앱 주소 (`설치안내.md`). 비우면 시트 없이 |
| `totalFloors` | 전체 층수 (600) |
| `seed` | 맵 번호. 같은 번호면 모든 학생이 같은 맵 |
| `quiz` | 퀴즈 층 (`firstFloor`층부터 `every`층마다 `count`문제) |
| `timeLimitSec` | 등반 시간 제한(초). 900 = 15분, 0 = 제한 없음 |
| `score` | 점수 공식의 숫자들 |
| `step.hopTime` | 한 칸 뛰는 시간 (작을수록 빠름) |
| `combo.timeout` | 몇 초 동안 안 오르면 콤보가 끊길지 |
| `zones` | 높이별 난이도 (계단, 낭떠러지 확률, 최대 추락 층수, `name` 연습 버튼 이름, `hazards` 장애물·겹침·빠르기) |
| `obstacles` | 장애물 속도·간격 (가시공, 바나나, 발판 부서지는 시간, 도토리, 돌풍, 맞았을 때 튕김, 무적 시간) |
| `map` | 미리 검사한 맵 번호 (아래 참고) |

`world`, `player`, `fixedStep`은 그림·계산이 맞춰져 있으니 고치지 마세요.

### 맵 번호(`map`) — 학생 휴대폰에서 빨리 열리게

600층 맵을 검사(모든 계단에서 봇이 올라가 보기, 장애물 공정성 등)하려면 PC에서도 1~2초, 휴대폰에서는 더 걸려요.
그래서 검사는 미리 해 두고, 학생 기기는 `map`에 적힌 값으로 검사 없이 바로 만듭니다.
`seed`·`zones`·`obstacles` 같은 맵 설정을 고치면 `map`이 맞지 않게 되어 게임이 처음부터 검사하고(느림), **새 `map` 줄을 안내**해 줘요.
그 줄(또는 조정 패널의 **맵 번호 다시 찾기** 결과)을 `config.js`의 `map` 자리에 붙여 넣으면 다시 빨라집니다.

## 조정 패널 — 주소 끝에 `?debug`

예: `index.html?debug` (claude.ai 링크에서는 주소 끝에 `#debug`) 로 열면 왼쪽 위에 ⚙ 버튼이 생깁니다.

- 슬라이더로 한 칸 뛰는 시간·콤보·중력·카메라·장애물 속도와 간격을 바꾸며 **바로** 플레이해 볼 수 있어요.
- **설정 복사** → `config.js`의 해당 부분에 붙여 넣고 새로고침 (새로고침해야 공정성 검사를 다시 받아요).
- **봇 켜기**(퀴즈는 자동 정답) · **층으로 이동** · 구간 바로 가기 · **퀴즈 건너뛰기** · **1분 남기기**(시간 종료 화면 확인)
- **이 시드로 맵 만들기** / **맵 번호 다시 찾기**

## 자동 테스트 — `tests.html`

`tests.html`을 열면 물리·탭 이동·콤보·600층 맵·장애물·퀴즈·점수·학생 정보·증명서·설정·구글 시트(가짜 시트로 Apps Script 전체 흐름, 연결 끊김) 테스트 170개가 실행되고(약 30초) 맨 위에 `PASS 170/170`처럼 결과가 나옵니다.
(로컬 서버에서 열어야 해요. 파일 더블클릭으로는 일부 브라우저가 막을 수 있어요.)

`config.js`에 잘못된 값을 넣으면 게임 화면에 **어떤 값을 어떻게 고치면 되는지** 안내가 나옵니다.
